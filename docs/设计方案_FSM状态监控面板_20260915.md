### 1.1 ⚠️ 一处口径冲突：UI 规则「非 S1 置灰」≠ 后端 `box_frozen` 字段

需求交互规则 3 是**视觉规则**：非 S1 震荡态 → 箱体面板置灰 + 提示"箱体冻结"。
但后端已有一个**独立字段** `ctx.box_frozen` / `box_frozen_at`。实测两者当前**互相矛盾**：

```
state     = S4_TREND_FADE   → 按 UI 规则 应「置灰/冻结」
box_frozen= false           → 按字段真值 箱体并未冻结
box_frozen_at = ""          → 从未冻结过
```

**风险**：若把 UI 规则直接写成"非 S1 就显示冻结"，面板会**掩盖真实字段值**，让人误以为箱体真的冻结了；
而这个字段恰恰是策略侧（`state_strategy.py:1012` 附近）判定是否允许入场的依据之一。

**建议**：两者分开呈现 —— 置灰沿用 `state != 'S1_OSC'`（视觉），同时把 `box_frozen` / `box_frozen_at` 作为**独立徽标如实显示**；
若二者不一致就如实展示不一致（这本身是有价值的观察信号）。

## 2. 真实数据契约（面板的 5 个数据源）

### 源 A：Redis 实时快照（4/7 个键存活）

| 键 | 实测 TTL | 关键字段 | 用途 |
