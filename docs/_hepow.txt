第一章  设计哲学
1.1  为什么叫‘和乘幂’？
‘和’指的是信号的加法融合（多周期、多因子的加权和）；‘乘幂’指的是信号的幂函数调整（通过幂指数 k 改变信号的凸性）。两者结合形成一个统一的数学框架：广义均值（Power Mean）。
这个框架的核心优势是：通过一个参数 k ，就可以在‘追求共识’和‘追随强者’之间无缝切换——不同的市场环境需要不同的融合策略，而不需要不同的代码逻辑。
k = 1.0: 加权平均（平衡中性，给予所有因子相等语音）
k > 1.0: 凸增强（强者更强，信号中的最强因子主导）
k → +∞: 取最大值（只信最强因子，其他忽略）
k < 1.0: 凹收敛（要求共识，单个强因子被拑制）
k → 0: 取几何平均（严格共识，任一因子为零则总分为零）
1.2  为什么主周期是 M5？
量化交易的本质是高频采样 + 精确执行。M5 是黄金市场中‘时间精度’与‘噪声可控性’的最优平衡点：
M1：噪声过高，点差吃掉盈余，适合计量微结构但不适合主执行
M5：每 5 分钟一根，足够快捷捕捉趋势起点，又不至于被噪声淹没。一天 288 根，信号密度合理
M15+：太慢，对于‘精确买卖点’目标而言精度不足
对应到整合方案的 5 周期体系：M5 是‘入场层’（文档原定为 M15，但量化交易主周期应为 M5），上层 H1/H4/D1 保持不变。M30 可选作为过渡层。
1.3  与现有系统的关系
本策略是在〈信号系统整合策略方案〉基础上的进一步优化。主要变化：
主执行周期从 M15 调整为 M5（适配量化交易）
新增一个信号源：微结构动量幂律信号（Microstructure Momentum Power-Law Signal）
核心评分从‘加权和’升级为‘和乘幂广义均值’
保留整合方案的迟滞状态机、共振矩阵、6维评分卡、双模式入场、动态仓位

第二章  和乘幂核心算法
2.1  广义均值评分公式
给定 N 个因子的方向性评分 f_i ∈ [-1, +1]，每个因子的权重 w_i ≥ 0，满足 Σw_i = 1，以及幂指数 k > 0：
和乘幂评分（Harmonic Power-Mean Score, HP-Score）:

  HP-Score = (Σ_i w_i × |f_i|^k)^(1/k) × sign(Σ_i w_i × f_i)

其中:
  Σ_i w_i × |f_i|^k → 幂加权和（强度）
  (…)^(1/k) → 幂开方（归一化）
  sign(Σ_i w_i × f_i) → 加权和的符号（方向）
方向和强度分离：方向由简单加权和决定（‘和’），强度由幂加权和再开方决定（‘乘幂’）。这两者独立，互不干扰。
2.2  幂指数 k 的自适应机制
这是‘和乘幂’的灵魂——幂指数 k 不是固定的，而是根据市场状态动态调整：
市场状态
k 值
行为特征
强趋势 (TREND)
k = 1.8 ~ 2.5
凸增强，最强因子主导，跟随趋势不犹豫
震荡 (RANGE)
k = 0.5 ~ 0.8
凹收敛，要求多因子共识，拑制单一因子假突破
转换 (TRANSITION)
k = 1.0
平衡中性，不偏向任何单一因子
趋势衰竭 (TREND_FADE)
k = 2.0 ~ 3.0
强凸增强，只信号最强因子（动量衰竭时唯一保留的信号）
k 的动态调整公式:
  k = k_base × (1 + α × (ADX_norm - 0.5) + β × (BBW_pct - 50)/100)

其中:
  k_base = 1.5 (中性基准)
  ADX_norm = ADX/50 ∈ [0,1] (趋势强度归一化)
  BBW_pct = 布林带宽分位数 ∈ [0,100]
  α = 0.8 (ADX影响权重) | β = 0.4 (BBW影响权重)
  结果范围: k ∈ [0.5, 3.0]

逻辑: 趋势强(高ADX)+波动扩张(高BBW) → k↑→凸增强
      趋势弱(低ADX)+波动收缩(低BBW) → k↓→凹收敛
2.3  为什么这样设计能提升胜率？
传统加权和的核心缺陷是：一个很强的信号可以被几个弱信号拉平。例如，强趋势中 ADX很高但 RSI 超买，加权和会被 RSI 拉低，导致错过趋势。
和乘幂解决了这个问题：在强趋势中 k>1 使强因子（ADX/ER）的影响力指数级增大，而弱因子（RSI超买）的影响被友制。这意味着‘趋势中不会被超买超卖喊停’——这是 co_source 中 RSI过热拑制（×0.3/0.5）的更优解。
反过来，在震荡市中 k<1 使任何单个强因子的假突破被拑制，只有多个因子共识时才产生高分——这是 co_source 中 RANGE闸门的更优解。

第五章  新信号源：微结构动量幂律信号
5.1  为什么需要新信号源？
现有系统（co_source + 文档设计）的信号都是基于 K线收盘确认的，存在‘延迟确认’问题：等 K线收盘时，最优价格已经过去。量化交易需要更快的预警信号。
微结构动量幂律信号利用 M1 或更细粒度的数据，通过价格加速度和动量的幂律衰减来提前捕捉趋势变化。这不是替代现有信号，而是作为‘前置预警’与‘入场时机确认’的增强器。
5.2  核心原理
幂律衰减（Power-Law Decay）是金融市场的基本统计规律：最近的价格变动对当前状态的影响远大于历史价格，且影响力按时间的幂函数衰减。传统的移动平均线性均衡对待所有时间点，而幂律加权能更准确地反映市场的‘记忆’。
幂律动量加权公式:

  微结构动量 MM(t) = Σ_{i=0}^{N-1} w_i × r(t-i)

  其中:
    r(t-i) = log(P(t-i)/P(t-i-1))  → 对数收益
    w_i = (i+1)^(-α)  → 幂律权重，α控制衰减速度
    α = 0.5 (默认) → 较慢衰减，更平滑
    α = 1.0 → 中等衰减，平衡
    α = 2.0 → 快速衰减，敏捷
    N = 20 (回看窗口，M1 为单位)

5.4  与和乘幂的融合
微结构动量信号不直接下单，而是作为和乘幂评分的一个特殊因子参与计算，但权重与其他因子不同——它是‘时机优化器’：
微结构动量作为第 7 因子:
  f_mm = MM(t) / |MM_max| ∈ [-1, +1]
  权重: 0.15 (趋势市中主导时机)，0.10 (震荡市中辅助确认)
  特殊规则: 当 |f_mm| > 0.7 且其他因子中有一个也超过 0.5 时
    → 触发‘共振加速’，将总评分的 k 值临时提升 +0.3
    → 这意味着微结构动量和宏观因子共振时，信号更凸

第六章  信号合成与评分
6.1  和乘幂合成算法完整流程
输入: 7个因子的方向性评分 f = [f_adx, f_er, f_ma, f_bbw, f_hurst, f_rsi, f_mm]

步骤 1: 加权和方向裁定
  dir_sum = Σ w_i × f_i
  若 |dir_sum| < 0.01 且 max(|f_i|) < 0.20 → NO_TRADE (信号太弱)
  若 dir_sum > 0 → 方向 = BUY
  若 dir_sum < 0 → 方向 = SELL

步骤 2: 幂加权和强度计算
  每个因子取绝对值 |f_i|
  加权幂和 = Σ w_i × |f_i|^k
  HP-Score_strength = (加权幂和)^(1/k) ∈ [0, 1]

步骤 3: 合成最终评分
  HP-Score = HP-Score_strength × sign(dir_sum)
  转换为百分制: hp_100 = HP-Score_strength × 100

步骤 4: 体制感知权重调整
  根据当前体制(TREND/RANGE/TRANSITION/FADE)选择 w_i 和 k

步骤 5: 多周期共振校准
  verdict = D1×0.25 + H4×0.35 + H1×0.25
  若 verdict 与 hp 方向矛盾且强度高 → 警告
  若 verdict 与 hp 方向一致 → hp × (1 + |verdict| × 0.1) → 共振加成

步骤 6: 微结构动量共振加速
  若 |f_mm| > 0.7 且 max(|f_others|) > 0.5 → k += 0.3, 重算 hp
6.2  与评分卡的结合
HP-Score 是‘趋势强度评分’，告诉你市场有没有在趋势中。但是否应该下单，还需要第二个维度：评分卡。
信号等级判定:
  评分卡总分 = 25×共振分 + 20×状态分 + 20×入场分 + 15×位置分 + 10×波动分 + 10×时段分

  其中共振分 = |verdict| × 100 (多周期一致度)
  状态分 = hp_100 (和乘幂强度)
  入场分 = 根据当前的入场技术条件评分(是否在回踩位/K线形态/RSI状态)
  位置分 = 距支撑阻力距离评分
  波动分 = ATR分位评分(30-70最佳)
  时段分 = 伦敦/纽约重叠盘=10, 亚盘=5, 数据前=0

  等级划分:
  评分卡总分 ≥ 75 且 hp_100 ≥ 60 → S级
  总分 ≥ 75 或 (hp_100 ≥ 60 且 总分 ≥ 60) → A级
  总分 ≥ 60 → B级
  总分 ≥ 45 → C级
  总分 < 45 或 hp_100 < 30 → 红灯(禁止开仓)

入场分批: 触带40% + 反转确认 60%
止损: S 下方 1.2×ATR(M5)
止盈: TP1=MA20中轨(50%) + TP2=R-0.3×ATR(50%)
要求 R:R ≥ 1.5
8.3  动态仓位与加仓
单笔风险 = 账户净值 × 1% (S级 1.5%)
仓位手数 = 单笔风险/(SL距离×合约价值)
波动调整: ATR分位>80%时仓位×0.5
微结构调整: |f_mm|>0.8 且动量加速时仓位×1.2

金字塔加仓(仅 S/A级 + 浮盈):
  +1R后 M5回踩确认→加 50%初始仓
  +2R后再回踩确认→加 25%
  每次加仓后全部止损上移至最近 swing low下方0.5×ATR
  总仓位风险敞口≤ 账户 2%
8.4  出场体系
优先级(先到先执行):
① 硬止损: 入场价 - 1×ATR(H1) (永不后移)
② 吊灯跟踪: 浮盈>1.5R后 Chandelier=最高收盘-3×ATR(H1)
③ 衰竭信号(ADX见顶回落+DI收敛+RSI背离): 止盈 50%
④ 结构破坏(swing low破位或收盘程0.618斐波): 全部离场
⑤ V型反转(单根反向振幅>2.5×ATR且收反向三分之一区): 市价离场
⑥ 时间止损: 入场 20根 H1 后浮盈<0.5R → 离场
⑦ 微结构衰竭: MM从高位快速下降超过阈值 → 止盈 50%

第十章  AI 辅助层
10.1  LightGBM 信号质量评分器
预留接口，待历史信号数据充分后接入。不直接产生信号，只做质量过滤：
标签: 入场后 12根 M5内先触+1.5R=1，先触-1R=0
特征(~25个):
  - 和乘幂全部原始值: hp_score, hp_strength, dir_sum, k
  - 全部因子原始值: adx, +di, -di, er, bbw, bbw_pct, hurst, rsi, mm
  - 多周期: H1/H4/D1的 TrendScore与方向
  - 入场微观: 距EMA20距离(ATR)、确认K线实体占比、回踩深度
  - 环境: 时段 one-hot、ATR分位、点差、距下一红色事件分钟数

使用方式:
  p < 0.50 → 过滤信号(不下单)
  p ∈ [0.50,0.60) → 降一级(C→红灯, B→C)
  p ∈ [0.60,0.70) → 保持原级
  p ≥ 0.70 → 升一级(B→A, A→S)

纪律红线: AI永远只有否决权和降级/升级权，没有独立开仓权

第十二章  实时数据流
12.1  信号生产管线
0. 市场熔断检查: 日亏>3%→停机 | 连亏5笔→冷却

1. 获取多周期 K线: PG hcm_market.klines + Redis live bar
   每周期独立计算指标

2. M1 微结构数据处理:
   计算幂律加权动量 MM(t)
   产出动量加速/衰竭/反转信号

3. 每周期状态机运行:
   M5(轻量方向) → H1(迟滞主状态) → H4(迟滞方向层) → D1(轻量方向)

4. 和乘幂评分:
   加权和方向裁定 + 幂加权和强度计算 + 体制权重调整 + 共振校准 + 微结构加速
   → HP-Score + hp_100

5. 多周期共振裁决:
   verdict = D1×0.25 + H4×0.35 + H1×0.25
   状态组合规则→策略权限和仓位约束

6. 评分卡打分:
   6维评分卡→S/A/B/C/红灯等级

7. 门控检查:
   信号质量门 + 自适应门槛 + 风控门

8. [可选] LightGBM过滤:
   p<0.50→过滤 | p 0.50-0.60→降级 | p≥0.70→升级

9. 执行决策:
   选择入场模式(回踩/突破) | 计算动态仓位 | 设置SL/TP

10. 发布信号:
   Redis Stream + PostgreSQL双写
