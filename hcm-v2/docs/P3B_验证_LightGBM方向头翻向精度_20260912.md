# P3-B 验证报告：LightGBM 方向头（dir_lm）翻向精度

> 授权（2026-09-12）："先离线验证 LightGBM 方向头翻向精度" —— 在**不开门、不碰生产**前提下，用硬证据判断是否应开启 `hexp.dir_lm_flip_enabled`。
> 只读侦察 + 离线统计，无写操作。

## 1. 数据接口侦察（先查前提，再下结论）

- `ai_direction` / `ai_dir_prob` 由独立 sidecar `quality_scorer.py` 每 ~5s 写 Redis `hcm:live:hexp:ai:XAUUSD`（TTL=15s），**不落历史库**（`scheduler.py:835-864` 读取后传入 `hexp_engine.py` 的 dir_lm 翻向段 `:1532-1563`）。
- 但 `quality_scorer.py:_record_raw`（`:1138-1168`）**每 M5 棒把方向头原始预测落库 `hcm_ai.ai_pred_raw`**（head='direction'，pred_class∈{-1,0,1}，cal_p = 防抖后 `ai_dir_prob`）。
- `:1863` 写入 `ai_pred_raw` 的 `cal_p` 正是 `_ai_dir_prob`（即翻向门真正读取的 `ai_dir_prob`）。→ **可用真实历史 dir_lm 序列，无需离线重算模型**。

## 2. 数据可用性（硬约束）

- `ai_pred_raw` 方向头数据：**仅 155 行，全部落在 2026-09-11 08:00–20:55（单日 ~13h）**。生产 `ai.lm.dir_enabled=true` 自该时点起才落库方向头。
- **09-10（跌日）无 dir_lm 数据** → 无法做双向样本验证（局限见 §6）。
- 真实成交：09-11 08:00–20:55 窗口内 **24 笔**（`hcm_trading.positions`）。

## 3. 证据一：默认阈值下翻向门是"死门"

`cal_p`（=ai_dir_prob）分布（75 个 BUY/SELL 行）：min=0.340 / max=0.598 / avg=0.404
**≥0.65 的行数 = 0**；≥0.55 仅 4 行；≥0.50 仅 10 行；≥0.45 仅 18 行。

→ `hexp.dir_lm_flip_prob` 默认 **0.65**，翻向触发条件 `ai_dir_prob ≥ 0.65` **永远不满足** → 即使开门，翻向门也**永不触发（空操作）**。

## 4. 证据二：逐棒方向精度（弱 / regime 污染）

仅统计 BUY/SELL 信号；前向收益符号为真相；前向 6/12/24 棒 = 30min / 1h / 2h。

| 阈值 T | n   | 30min  | 1h    | 2h     |
|--------|-----|--------|-------|--------|
| 0.40   | 29  | 55.2%  | 51.7% | 93.1%  |
| 0.45   | 18  | 66.7%  | 44.4% | 100%   |
| 0.50   | 10  | 70.0%  | 40.0% | 100%   |
| 0.55   | 4   | 75.0%  | 0.0%  | 100%   |
| 0.65   | 0   | -      | -     | -      |

基准：样本 BUY 28% / SELL 72%（随机猜方向期望 ~50%）。
- **30min 精度仅 55–75%**，略高于随机；1h 在 40–51% 区间震荡（含 T=0.55 时 0%，n=4 噪声）。
- 2h 精度 93–100%，但样本小（n=10–18）且 09-11 是**单边下跌日**、dir_lm 以 SELL 为主 → **高度 regime 污染，不能视为方向头稳定技能**。

## 5. 证据三：交易级翻向影响（24 笔真实成交）

每笔成交匹配其 `open_time` 最近（≤5min）的 dir_lm 棒：

| 分组                  | n  | 胜率   | 平均PL  |
|-----------------------|----|--------|---------|
| 同向（dir_lm=入场方向）| 6  | 66.7%  | +0.78   |
| 反向（dir_lm≠入场方向）| 4  | 0.0%   | -6.49   |
| HOLD（dir_lm 中性）    | 14 | 42.9%  | -6.37   |

唯一 4 笔"反向"交易（pid 4370-4373）**全部亏损、avgPL -6.49** —— 表面看"若翻向可避损"。
但其 dir_lm **prob=0.34**，低于任何合理阈值（0.40+）。翻向汇总：

| 阈值 T | 触发翻向笔数 n_flip | 翻向中盈利 | 翻向中亏损 | 翻向胜率 | 同向胜率 |
|--------|--------------------|-----------|-----------|---------|---------|
| 0.40   | 0                  | 0         | 0         | -       | 66.7%   |
| 0.45   | 0                  | 0         | 0         | -       | 66.7%   |
| 0.50   | 0                  | 0         | 0         | -       | 66.7%   |
| 0.55   | 0                  | 0         | 0         | -       | 100%    |

**结论：在任意合理阈值（≥0.40）下，09-11 的 24 笔成交中 n_flip=0 —— 翻向门一笔都不触发。**
那 4 笔亏损的"反向"信号置信度仅 0.34，翻向门正确地不会据此翻向。

最大亏损簇 4364-4369（PL -7 ~ -21）当时 dir_lm 为 HOLD、prob 0.45–0.49 —— 方向头**也未预警**；翻向机制仅作用于 BUY/SELL 分歧，对此类"追单后反转"无能为力。

## 6. 结论与建议

**不开门 `hexp.dir_lm_flip_enabled`。** 双重硬证据：
1. **概率阈值错配**：真实 `ai_dir_prob` 系统性压缩（max 0.598、均值 0.404），默认 `flip_prob=0.65` 永不满足 → 开门 = 空操作。
2. **无高置信反向事件**：24 笔真实成交中唯一反向信号置信度均 =0.34，任何合理阈值下 n_flip=0 → 翻向门对实盘一笔不变。

方向头本身技能薄弱且 regime 依赖（30min 仅 55–75%，2h 高值受单边日污染），**不足以支撑"强制翻向"**（`hexp_engine.py:1548` `direction = ai_direction` 是高爆炸半径动作：把 HEXP 合成方向直接推翻，可能把"滞后但正确"的方向翻成"追错"）。

**若日后仍想启用，前置条件（按顺序）：**
- (a) **先修方向头校准**：`ai_dir_prob` 被 isotonic/NumpyCalibrator 压缩在 0.34–0.60。查 `calib_dir_np_v{N}.pkl` 是否退化（`quality_scorer.py:_calib_is_degenerate` 已有退化检测+退回 raw 逻辑）；或重训使高置信信号能达 ≥0.65。
- (b) **扩大样本到多日**（含 09-10 跌日 + 震荡日），在 T=0.45–0.55 重测交易级 n_flip 与翻向后真实盈亏，确认 n_flip>0 且翻向胜率显著高于随机，再**二次授权**开门。
- (c) 即便开门，建议把"强制翻向"降级为"软降级/否决"（沿用 `quality_gate` 既有 AI 否决权，`hexp_engine.py` 外 `ai.lm.direction_fuse` 路径），而非推翻 HEXP 方向 —— 爆炸半径更小。

## 8. 风险与局限

- 单日样本（09-11，单边下跌），n 小（155 棒 / 24 笔）；统计结论为"指示性"非"显著性"。
- 09-10 跌日无 dir_lm 落库 → 未验证"涨→跌"反转场景（恰是翻向最该见效的场景）。
- 未重算模型，直接用生产落库真实 dir_lm（更可靠，避免特征/verdict 重建偏差）。
