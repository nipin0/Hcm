# 变更：hexp 微动量追单否决（|mm| ≥ 0.5 拒单）

- 日期：2026-09-18
- 授权：用户「|mm| ≥ 0.5 拒单」
- 变更性质：**hexp 方向裁决新增硬护栏**（会减少下单）
- 回滚：`set_cfg.py hexp.mm.veto_abs 0`（秒级，无需重启）

---

## 1. 归因依据（`tools/_scratch/range_trend_attrib.py`）

**样本**：XAUUSD M5，45 天，**1433 条 hexp 已发布方向信号**（`signal_mode LIKE 'HEXP%'`，
`signal_dir ∈ BUY/SELL`）。判据 `Rprod` = TP `1.5×SL` / SL `2.5ATR`（贴合 `hexp.exec.rr_min=1.5`
+ 宽时段止损），成本 0.12ATR；结构量 MAE/MFE（ATR 归一最大逆行/顺行）、nat24（24 根净位移）。

> ⚠ 判据说明：1.5ATR **对称**双障碍在 4h 窗口内落在噪声带（总体 MAE≈MFE≈3.35ATR ⇒ 胜率恒≈50%），
> **无判别力**；故结论以 `Rprod` + MAE/MFE/nat 为准。

| 档位 | n | **Rprod** | win | **MAE中位** | **nat24** |
|---|---|---|---|---|---|
| 基线（全部） | 1433 | +0.002 | 0.509 | 3.35 | −0.08 |
| **被拒档 \|mm\|≥0.5** | **35** | **−0.614** | 0.457 | **17.46** | **−3.13** |
| 　└ 且 TREND | 16 | **−0.851** | 0.562 | 17.64 | **−6.29** |
| 　└ 且 NEUTRAL | 19 | −0.415 | 0.368 | 17.45 | −0.47 |
| **剩余 \|mm\|<0.5** | 995 | +0.034 | 0.495 | 3.00 | −0.15 |

**语义**：微动量已冲到极值 ⇒ 行情已走出大半，此时顺势进场 = 追顶/追底。
MAE 中位 **17.46×ATR**（总体的 **5.2 倍**）是"进场即逆势"最直接的刻画。

**与既有护栏的互补性（不重复）**：
- `momentum_flip` 拦「动量**逆向**」（`mm_aligned` 与信号方向相反）；
- 本闸拦「动量**同向但已极端**」—— 此前**无任何闸门覆盖**（被拒档 35 条全部已 `passed` 发布，
  证明它们确实绕过了 momentum_flip/drain/range_hurst）。

**旁证**：被拒档 35 条**全部为 SELL**（当前样本内 BUY 侧未出现 |mm|≥0.5）⇒ 该闸在单边上涨行情中
主要作用于空头补涨单；方向覆盖度可能随行情变化。

## 2. 改动（`hcm-signal-tower/signal_tower/hexp_engine.py`）

| # | 位置 | 内容 |
|---|---|---|
| 1 | `_DEFAULTS`（L322） | 新增 `"hexp.mm.veto_abs": 0.0`（0 = 关闭）。**必须登记**：未登记则 `_reload_locked` 不快照该键 ⇒ 配置中心改了永不生效（本仓库已知缺陷类，见 L318-336 注释） |
| 2 | 硬护栏栈 A-4（L2596-2613） | `\|mm\| ≥ veto_abs` 且 `direction ∈ BUY/SELL` → `direction=NO_TRADE` / `passed=False` / `sr.mm_chase_blocked=True` / `fallback_reason=hexp_mm_chase_veto(...)` |
| 3 | `_ts_guard_blocked`（L2891） | 追加 `or getattr(sr, "mm_chase_blocked", False)` ⇒ **趋势启动覆写不得复活**该信号（该覆写会绕过 grade 闸门，是唯一的复活路径） |

**为什么放在硬护栏栈内**：与 `extreme_reversal / momentum_drain / momentum_flip / range_hurst`
同栈，天然被 `_ts_guard_blocked` 覆盖，且 `fallback_reason` 前缀**不在**注入白名单
（`hexp.entry_gate.overridable_reasons=hexp_no_direction`）⇒ 下游注入（value_drive / range_mr /
micro_state）也不会把它翻回来。

## 4. 边界与待观察

1. **自然触发计数**：`|mm|≥0.5` 在 45 天里仅 35 次（≈0.8/天）；当前市场 `max|mm|≈0.014`，
   故**自然触发验证尚未发生**。观察项：
   ```sql
   SELECT count(*), left(fallback_reason,40) FROM hcm_signal.signals
   WHERE signal_mode LIKE 'HEXP%' AND fallback_reason LIKE 'hexp_mm_chase_veto%'
     AND created_at > now() - interval '7 days' GROUP BY 2;
   ```
   或日志 `BLOCK hexp_mm_chase_veto`。
2. **反向单（`hexp.reverse_order_enabled=true`）不受本闸约束**：那是"momentum_flip 之后的反手接刀"
   独立通道，属另一议题；若需一并否决请单独决策。
3. **样本偏差**：单品种 / 45 天 / 单边上涨 ⇒ `TREND` 与 `SELL` 的差结果部分来自行情方向本身，
   需跨品种与跨区间复核。
4. **未做影子期**：本次为直接生效（按用户指令）。若担心误伤，可先置 `0` 并观察
   「若启用会被拦掉的信号」——但需另加影子日志字段，当前未实现。
5. 同类候选闸（离线已量化，**未实施**）：`adx≥35`（n=476, Rprod −0.233）、
   `phase=establish`（n=160, win 41.2%）、`BUY pos≥0.6`（n=265, win 40~43%）。
