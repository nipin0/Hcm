- 本样本 P1 拦截的 22 笔 **100% 是 SELL 且 h1_dir=UP**（"逆 H1 上涨趋势卖"）。

## 4. 结论（立论判定）
- ❌ 原立论"P1 砍 NEUTRAL 亏损池"**不成立**：NEUTRAL 仅 −4.85（非亏损池），且 P1 仅触达 15/55 笔 NEUTRAL。

- 🔧 最大亏损池 `TREND` regime（−140.29）是顺趋势单失败，P1（只拦逆趋势）**结构上无法解决**；需另起机制（如趋势 regime 下的 SL 收紧 / 趋势衰竭退出 / HEXP 趋势判读校准），而非趋势优先拦截。
