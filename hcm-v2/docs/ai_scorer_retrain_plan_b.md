# LightGBM 信号质量评分器 · B 档重训增强计划

> 状态：计划文档（待排期实施，非生产代码）
> 关联：A 档推理端增强（`tools/quality_scorer.py` 2026-08-18 已上线，配置热调）
> 铁律：本档为 C 提案·改进，触及训练管线/模型结构属第二、五条核心机制改动，实施前须再出变更说明待确认。

## 1. 背景与目标

A 档已根除"评分变 0"脆弱点（Z-score + EMA 平滑 + min_valid 回退），但仍是**单点预测 + 单棒特征**：

- 只取 `kl.iloc[-1]` 一根 M5 棒，完全忽略"信号启动形态"（多根棒的趋势/动量结构）。
- 模型只给 `p_raw` 一个点估计，无不确定性，无法区分"高确信良机"与"模糊噪声"。
- 状态头是硬 one-hot 归类，边界样本被强制分桶，丢失过渡信息。

B 档目标：**增强信号捕捉能力**（而非噪声放大）——让模型在"信号刚启动"的早周期就给出有区分度的质量分，并自带置信度。

## 2. 范围（两大部分）

### 2.1 特征工程增量（多根棒滚动统计）
在 `quality_features.py` 的 `enrich_klines` 后新增 `_add_rolling_shape(kl)`，产出近 N 根（6/12）棒的滚动统计量：

| 新特征 | 语义 | 捕捉能力 |
|---|---|---|
| `mom_slope6` / `mom_slope12` | 近 6/12 根收盘动量斜率（回归系数归一化） | 信号启动的加速度 |
| `atr_trend6` | ATR 近 6 根相对变化率 | 波动率扩张/收敛（突破前常降波） |
| `dev_accel20` | `dev_z_ema20` 一阶差分（偏离加速度） | 趋势确认/衰竭 |
| `di_net_slope6` | `di_net` 近 6 根斜率 | 方向动能的持续性 |
| `macd_hist_slope3` | MACD 柱状近 3 根斜率（已有 `macd_slope3` 是单点，补趋势） | 量能成熟度 |
| `bbw_trend6` | 布林带宽近 6 根变化 | 收敛突破前兆 |

**约束**：全部用 `shift(1)` 后历史值，禁止未来数据泄露（铁律五·量化红线）。N 取固定窗口，不热调，避免训练-推理分布偏移。

### 2.2 模型结构升级（双头 + 软状态）
- **质量头 + 不确定性头**：LightGBM 多任务（或两独立 Booster），不确定性头输出 `σ`（同分布分位数回归或对称损失），`ai_score = p_raw × (1 - k·σ)`，低频高确信信号才给高分 → 真正增强捕捉而非放噪。
- **状态头改 softmax 软概率拼接**：替代硬 one-hot，把 `P(state=TREND/PULLBACK/REVERSAL/RANGE)` 作为连续权重拼回质量头特征，保留过渡信息。
- 特征列顺序须在 `quality_scorer.py` 的 `FEATURE_COLS` 与 `train_signal_quality.py` 中**同步扩展**，并启用 `--audit` 对齐校验（已有审计机制）。

## 3. 训练数据要求

- 现有 `labels.csv`（419 条，正样本 57/16%）严重不平衡 → 需扩充至 ≥2000 条、正样本 ≥30%（重跑 `build_labels.py --ds-calibrate` 采集新窗口，含近期实盘成交/未成交对照）。
- 修复已知训练 bug：
  - `train_signal_quality.py` 的 `drop_cols` 须含 `ds_calib_weight`（已修，记忆 58667758），避免目标泄漏。
  - 滚动特征列必须与推理侧 `enrich_klines` 完全一致（审计 diff）。
- 保留 isotonic 校准器训练，但评估档位数需 ≥ `CALIB_MIN_LEVELS`(4)，否则 A 档 `score_one` 的退化混合兜底仍生效。

## 4. 推理端配套改动（实施 B 档时同步）

`quality_scorer.py` 的 `score_one` / 主循环：
- `score_one` 返回 `(p_raw, σ, predicted_state_probs)`，主循环用 `p_raw × (1 - k·σ)` 替代纯分位。
- `--audit` 输出新增滚动特征列，供训练侧对齐。
- 保留 A 档三开关（Z-score/平滑/min_valid）作为上线灰度护栏，新模型稳定后逐步关闭。

## 6. 排期与风险

- 周期：数据采集（1~2 天）+ 训练调参（1~2 天）+ 灰度（A 档开关护栏，1 天）。
- 风险：训练-推理分布偏移（靠 `--audit` + 列顺序同构根治）、过拟合（靠样本扩充 + 不确定性头正则）。
- 不触及：HEXP 原始信号方向（铁律五）、异步架构、缓存队列（仅 sidecar 内部模型升级）。
