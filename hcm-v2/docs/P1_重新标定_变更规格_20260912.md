# P1 重新标定 变更规格（加旋钮 · 保持 shadow · 零实时影响）

> 依据：P1_立论重审_趋势优先_20260912.md。结论：P1 是钝器式震荡过滤器（砍 RANGE 亏损 −95.35，但误杀盈利 63.6%，且对最大亏损池 TREND regime 结构性够不到）。重标定目标=加可调旋钮，让 canary 能压误杀、保亏损捕获。

## 1. 数据验证结论（支撑本规格）
- 微观态条件"仅非趋势才拦"是**空操作**：本样本 22 笔拦截已 100% 为 RANGE(18)/TRANSITION(4)，加条件不改变拦截集。
- **TRANSITION 拦截 4 笔 100% 盈利(+18.96)、亏损 0** → 拦截范围从 `RANGE,TRANSITION` 收窄到仅 `RANGE`：免杀 +18.96、亏损捕获不变(−117.51)，净改善 +18.96，误杀率 63.6%→55.6%。样本小(4笔)，方向性参考。
- `h1_strength` 全 99 笔未落库 → 强度阈值无法历史预校验，只能 canary 调。

## 2. 变更：加两个旋钮
### 2.1 hexp_engine.py:_tp_would_block（原 1559-1560）
原：
```
_tp_would_block = bool(_tp_confirmed and _tp_dir and direction in ("BUY","SELL") and direction != _tp_dir)
```
改为（在作用域已有 `_tp_state`(=period_states[primary]=M5微观态)、`_h1_str`、`cfg`）：
```
_tp_block_states = set(s.strip().upper() for s in str(cfg.get("hexp.trend_priority_block_states","RANGE,TRANSITION")).split(",") if s.strip())
_tp_block_min_strength = float(cfg.get("hexp.trend_priority_block_min_strength", 0.7))
_tp_would_block = bool(
    _tp_confirmed and _tp_dir and direction in ("BUY","SELL") and direction != _tp_dir
    and _tp_state in _tp_block_states          # 仅这些 M5 微观态拦截
    and _h1_str >= _tp_block_min_strength)     # H1 强度下限(比 confirm 的 0.5 更严)
```
> `_tp_state` 取值为 "RANGE"/"TREND_UP"/"TREND_DOWN"/"TRANSITION"（与落库 period_states 一致），故字符串比较成立。

### 2.2 默认值登记（两处须一致）
- `hcm-signal-tower/signal_tower/hexp_engine.py` 默认字典（~328 行 `trend_priority_mode` 旁）：
  `"hexp.trend_priority_block_states": "RANGE,TRANSITION"`, `"hexp.trend_priority_block_min_strength": 0.7`
- `hcm-web/web/api/hexp.py` 白名单（~206/302 行旁）：同值。
- **`hexp.trend_priority_mode` 维持 `"shadow"`**（不变）→ 闸门不动作，仅观测落库 trend_governance，零实时影响。

## 3. 行为影响
- 默认 `block_states=RANGE,TRANSITION` + `block_min_strength=0.7`：比原 P1 多了"H1 强度≥0.7"门槛（原仅 confirm 的 0.5），拦截更严；`block_states` 默认含 TRANSITION 即保留原范围。**默认即比原 P1 稍温和**（强度门槛更高）。
- 爆炸半径：仅当未来 flip `mode=on` 才真拦；当前 shadow 零影响。

## 4. canary 调参建议（待用户授权 flip on 后）
- 起点：`block_states=RANGE`（数据支持，免杀 TRANSITION 盈利），`block_min_strength=0.7`。
- 监控：误杀率↓（目标<40%）、RANGE 亏损捕获保持(~−95)、先碰SL↓；TREND regime 池 P1 不解决（需另起机制）。
- 3 天影子对照，达标全量否则回 shadow / 继续调参。

## 5. 回滚
- 配置中心改 `block_states`/`block_min_strength` 或 `trend_priority_mode=shadow` 即秒级回退。
