# P1 变更规格：激活趋势优先（站到正确方向 · 主线）

> 2026-09-12。Phase 0 实测后，P1 升为治本主线。本文是**变更前规格**（改配置值前先列键/值/爆炸半径，待用户确认应用方式）。
> 结论先行：**无需新写代码**——对称收口逻辑已存在于 `hexp_engine.py:1554-1574`，P1 = 配置翻转 + 趋势确认灵敏度调参。

## 1. 现有机制（已存在，只读确认）

`hexp_engine.py:1554-1574`（`_tp_mode` 取自 `hexp.trend_priority_mode`，默认 `shadow`）：

```python
_tp_would_block = bool(
    _tp_confirmed and _tp_dir and direction in ("BUY","SELL") and direction != _tp_dir)
if _tp_would_block and _tp_mode == "on":
    direction = "NO_TRADE"          # 真拦逆势单（涨中摸顶 SELL / 转跌抄底 BUY 都拦）
    sr.direction = "NO_TRADE"; sr.threshold_passed = False; sr.trend_priority_blocked = True
elif _tp_would_block:
    logger.info("... [SHADOW] trend-priority would-block ...")   # shadow 只观测不改裁决
```

- 顺向方向（如 `TREND_DOWN` + `SELL`）→ `_tp_would_block=False` → **放行（趋势跟随做空）**。已是对称。
- `_tp_confirmed` / `_tp_dir` 由主周期状态机 + H1 得出（`hexp_engine.py:1380-1410`）。
- 观测出口 `sr.trend_governance`（:1576）已落库 `signals.indicator_values._hexp.trend_governance`，Phase 0 即读此验证。

**所以 P1 的唯一实质动作 = 把 `_tp_mode` 从 `shadow` 翻到 `on` + 调低趋势确认门槛让网关真正触发。**

## 2. 变更键清单（current → proposed）

| 键 | 当前值 | 拟改值 | 作用 | 爆炸半径 |
|---|---|---|---|---|
| `hexp.trend_priority_mode` | `shadow` | **`on`** | 真拦逆势单（涨中摸顶 SELL / 转跌抄底 BUY），放行顺向 | **全局 XAUUSD 信号裁决** |
| `hexp.trend_start.hold_bars` | `90` | **`30`** | 趋势确认所需一致棒数↓ → 趋势更早确认、网关更常触发 | 趋势候选观测（`order_enabled=False`，当前不真下单） |
| `hexp.trend_start.bbw_max` | `20.0` | **`25.0`** | 压缩带阈值↑ → 更多 squeeze_breakout 候选被观测 | 同上（观测） |
| `hexp.trend_confirm_include_h1` | `True` | 保持 `True` | H1 参与趋势确认 | — |
| `hexp.trend_confirm_h1_ind_enabled` | `True` | 保持 `True` | H1RegimeClassifier 的 `h1_trend_direction` 参与 | — |

> 调参两项仅影响 `trend_start` **候选观测**（因 `hexp.trend_start_order_enabled=False`，当前绝不真下单）；`trend_priority_mode=on` 才是真正改变实时裁决的动作。

## 4. 爆炸半径与风险

- `trend_priority_mode=on`：全局即时拦截逆势单。上行市会拦掉"涨中摸顶 SELL"（好，正是 09-11 的 −41.9 亏损源），下跌市会拦掉"转跌抄底 BUY"（好）；**但若 H1/主周期趋势判断滞后**，可能在下跌日回踩时误拦合法趋势跟随 SELL（Phase 0 实测 6.8% 误杀率，须用 canary 监控）。
- 折损：趋势市成交量可能下降（逆势单被拦），但方向正确率应上升。
- 回滚：配置中心把 `trend_priority_mode` 改回 `shadow` 即恢复（无需改码）。
