# 跟单策略创新点：去跟单化（改变） × 持仓一致性（保留）

> 版本：v1.0.2 · 2026-08-24
> 关联设计：`docs/hexp_unified_signal_multi_account_design.md`
> 核心实现：`tools/mt5_bridge.py`（去跟单化）、`hcm-risk-engine`（同向保本闸门按账号）
> 铁律：`docs/hexp_config_min_grade_iron_rule.md`（调参 PG+Redis 双写）

---

## 一、背景：传统跟单的根本缺陷

传统跟单（复制主号成交单）链路：

```
信号广播(risk_passed) → 跟单号收到 → 等主号先建仓(A-护栏) → 用主号成交价做锚 → 复制下单
```

**缺陷**（实证）：
1. **"跟不上"**：跟单号必须等主号成交后，经 校验/快照/传输延迟 才复制，下单时点晚于主号秒级。
2. **价格漂移**：跟单号用主号 T0 成交价做滑点基准，价格已漂移 → `ENTRY_MISSED` 拒绝或强行走漂移价。
3. **主号耦合**：跟单号行为完全依赖主号成交事件，任一环节抖动即脱节。

---

## 二、创新点 1（改变）：去跟单化 —— 全部账户同信号、同链路、独立下单

**核心思想**：信号本身已是广播（所有账户收到同一份 `signal:risk_passed`）。与其"复制主号成交"，不如**让每个账户（含跟单号）对同一信号独立决策、独立下单**。

```
信号广播(risk_passed) → 主号桥 独立下单
                      → 跟单号桥 独立下单（同信号、同时机、同价格口径）
                      → 其他账户桥 独立下单
```

**实现要点**（`mt5_bridge.py`）：
1. **移除 A-护栏**（跟单号不再等主号建仓）。
2. **移除 master-fill 锚点**（跟单号用自身实时 tick + 信号 T0 entry_price，与主号同口径）。
3. **移除 master-pos 对账**（跟单号不再"主号无仓则 SKIP"）。
4. **reconcile 改为仅"清孤儿"**（不补缺失，错过即放弃）。

**效果**：跟单号与主号**同时**收到同一信号、**同时**独立下单，彻底消除"等主号成交"的秒级延迟与价格漂移，根治"跟不上"。

---

## 三、创新点 2（保留）：持仓管理一致性 —— 不是"完全脱钩"

去跟单化**只改变开仓的触发方式，不破坏持仓风险管理的一致性**。以下机制刻意保留：

1. **`_sync_follower_sl_tp`（跟单 SL/TP 镜像主号）**：跟单号持仓的 SL/TP 仍跟随主号快照，保证保本/移动止盈/追踪止损与主号一致，避免"主号已锁利、跟单号还在裸奔"。
2. **`_write_be_flags`（保本标志，按账号）**：每账号写自己的 `hcm:pos:be:{account}:{dir}`，供风控「同向保本闸门」按 `account_id` 独立判断"最新持仓是否达保本才可加仓"。
3. **共享信号级风控**：信号方向/极值/AI 分被拒 → 全部账户都不开（主号不开，跟单号也不开）。
4. **账号维度风控**：持仓数上限（`risk_max_open_positions`）、日盈亏熔断按各账号独立评估。

**设计哲学**：**开仓去耦合（根治跟不上）+ 持仓管理保一致（风险不脱节）**——两者分离，而非一刀切"完全跟单"或"完全独立"。

---

## 四、与既有"同向保本闸门"的协同

`risk-engine` 的 `_check_cooldown`（同向保本闸门）按 `account_id` 读取：
- 快路径：Redis 保本标志 `hcm:pos:be:{account}:{dir}`（桥秒级巡检写）。
- 回退：PG 查该账号最新同向 open 持仓的 SL。
- 判定：最新同向持仓达保本 → 放行（有信号即开单）；未达 → 禁止开新单。

这是"**秒级巡检持仓保本状态 → 控制加仓节奏**"的机制，去跟单化后对跟单号同样按账号生效。

---

## 五、架构收益

| 维度 | 传统跟单 | 本创新方案 |
|---|---|---|
| 开仓触发 | 等主号成交后复制 | **同信号独立下单**（同时机） |
| 滑点基准 | 主号成交价（已漂移） | **自身实时 tick + 信号 T0** |
| 持仓 SL/TP | 跟随主号 | **保留跟随主号**（保一致） |
| 保本判断 | 依赖主号 | **按账号独立写保本标志** |
| 信号级风控 | 依赖主号结果 | **共享信号级**（主号拒则全拒） |
| 账号持仓风控 | 无 | **独立持仓数上限 + 日盈亏熔断** |

---

## 六、验收与验证

- 跟单号下单时点与主号接近（无"等主号成交"延迟）。
- 跟单号不再因 master-fill 价格漂移触发 `ENTRY_MISSED`。
- 主号被风控拒单时，跟单号也不开（共享信号级风控）。
- 各账号独立持仓风控生效（单账号 max_open_positions/max_daily_loss）。
- 手动平仓/改单仍同步到所有账户。
